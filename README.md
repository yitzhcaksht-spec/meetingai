# MeetingAI — מערכת תמלול וסיכום פגישות

אב-טיפוס (MVP) לתמלול וסיכום פגישות בזמן אמת, מותאם לעברית מקצועית. פותח עבור חברת החשמל ישראל.

המערכת מקליטה את הדיון, מתמללת אותו חיה בתוך הדפדפן, מפיקה סיכום אוטומטי וטבלת משימות, ומחייבת אישור אנושי לפני הפצה. כל העיבוד מתבצע מקומית בדפדפן — השמע אינו עוזב את המחשב ואינו נשמר לדיסק.

## הדגמה חיה

לאחר פרסום ב-GitHub Pages, האתר יהיה זמין בכתובת:

```
https://<USERNAME>.github.io/<REPO>/
```

## יכולות עיקריות (MVP)

| יכולת | תיאור |
|---|---|
| הקלטה בלחיצה אחת | התחלה ועצירה של ההקלטה מכפתור יחיד, עם אינדיקטור ויזואלי וטיימר |
| תמלול עברית חי | תמלול אוטומטי בזמן אמת באמצעות Web Speech API של הדפדפן |
| סימון תוך כדי | סימון נקודה חשובה, סיכון או החלטה במהלך הדיון |
| סיכום אוטומטי | החלטות, נושאים פתוחים ודגלים — מבוסס על הנאמר בלבד |
| טבלת משימות | משימה, הסבר קצר, אחראי ותאריך יעד — שדה חסר מסומן "לא נקבע" |
| אישור אנושי | שלב חובה של אישור לפני הפצת הסיכום |
| ייצוא | העתקה ללוח או הורדה כקובץ טקסט |

## דרישות הפעלה

- דפדפן מבוסס Chromium (Chrome / Edge) — Web Speech API לעברית נתמך בו במלואו.
- חיבור אינטרנט להפעלת מנוע התמלול של הדפדפן.
- הרשאת גישה למיקרופון.

> הערה: התמלול בדפדפן מסתמך על מנוע ה-`SpeechRecognition` הזמין בו. ב-Firefox ובחלק מהדפדפנים אין תמיכה מלאה בעברית.

## הפעלה מקומית

מאחר שמדובר בקובץ HTML יחיד ללא תלות בבנייה, ניתן לפתוח אותו ישירות. להפעלת המיקרופון מומלץ להריץ דרך שרת מקומי:

```bash
# Python 3
python3 -m http.server 8000
# ואז לגלוש אל http://localhost:8000
```
